# Security Policy

## Scope

WinterIsComing for GNOME Shell runs locally inside your desktop session, makes **no network connections**, and stores only local user preferences via GSettings (`org.gnome.shell.extensions.winter-is-coming`).

## Reporting a Vulnerability

If you discover a security or stability issue (such as unintended input capture, privilege/lock-screen leaks, or crash triggers), please open a private security advisory on GitHub or report it directly to the repository maintainer before public disclosure.
